# Advantech OpenBMC – SOM-RM10

OpenBMC support for the **Advantech OpenBMC** module based on **ASPEED AST2600**  
(Tested with SDK **v09.06**).

This repository provides **board-specific OpenBMC support**, including:

- Yocto meta layers
- Device Tree sources
- Kernel and BMC drivers
- Platform configuration files

The primary goal of this project is **hardware bring-up and verification**
of OpenBMC on Advantech platforms.

---

## Supported Platforms
- **SOM-RM10** with **SOM-E781** carrier board
